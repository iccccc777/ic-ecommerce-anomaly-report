# 第 1 步：下载并确认数据

## 任务目标

拿到原始数据，并确认以下信息：

- 文件存在
- 文件大小
- 总行数
- 字段是否包含 user_id、item_id、category_id、behavior_type、timestamps
- 行为类型是否包含 pv、cart、fav、buy

## 操作

1. 打开 https://tianchi.aliyun.com/dataset/649
2. 登录后下载 `UserBehavior_raw.csv`（或下载后改名）
3. 把文件放到：

```text
C:\Users\ASUS\Desktop\project_a\data\UserBehavior_raw.csv
```

4. 用记事本或 VS Code 打开文件前几行，确认是逗号分隔、无表头、共 5 列；不同镜像的分隔符可能不同，当前本地文件是逗号分隔。
5. 在 VS Code 中打开 `C:\Users\ASUS\Desktop\project_a`
