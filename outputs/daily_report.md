# 电商经营日报初稿（12月2日—12月3日）

## 一、核心指标概览

12月2日（周六）与12月3日（周日）连续两天表现强势，DAU、PV、购买量均较上周同期显著增长。

| 指标 | 12月1日 | 12月2日（周六） | 12月3日（周日） |
|---|---:|---:|---:|
| DAU | 14,523 | 19,118 | 19,059 |
| PV | 191,463 | 241,527 | 242,349 |
| 收藏（fav） | 5,889 | 7,808 | 7,509 |
| 加购（cart） | 12,263 | 15,231 | 15,196 |
| 购买（buy） | 4,117 | 5,080 | 5,258 |
| buy_to_pv | 2.15% | 2.10% | 2.17% |
| buy_per_dau | 0.283 | 0.266 | 0.276 |

**关键结论：**

- **DAU 大幅高于同星期基线。** 12月2日周六 DAU 较上周六增长 38.5%，较移动均值高 33.0%，z-score 为 2.49；12月3日周日 DAU 较上周日增长 35.0%，较移动均值高 19.0%，z-score 为 2.42。两天均被判定为 **strong 级异常**。
- **购买量同步走强，但增幅低于 DAU。** 12月2日购买量较上周六增长 31.2%，12月3日较上周日增长 29.1%，均低于 DAU 同比增幅。购买 z-score 分别为 1.74 和 2.53，12月3日购买异常强度高于 DAU。
- **转化率基本平稳。** buy_to_pv 两天分别为 2.10% 和 2.17%，与 12月1日的 2.15% 接近，说明购买增长主要由流量增长驱动，而非转化率提升。
- **人均购买频次略降。** buy_per_dau 从 12月1日的 0.283 降至 12月2日的 0.266，12月3日回升至 0.276，仍低于 12月1日。结合 DAU 大增，说明新增活跃用户中有一部分尚未转化为购买。

## 二、异动定位

### 1. 同星期基线：增长是真实的，不是星期效应

12月2日、3日已分别与11月25日周六、11月26日周日对比。DAU 同比增幅分别为 38.5% 和 35.0%，购买同比增幅分别为 31.2% 和 29.1%。这说明本周末的增长**不能由“周末自然流量上升”解释**，而是存在额外的增量因素。可能原因包括：大促预热、外部投放、活动上线或季节性需求，但当前数据无法直接验证，需结合运营排期确认。

### 2. 类目：增量分散，无明显单一爆款类目

12月2日相对12月1日的类目购买增量 Top 5 中，最高增量仅为 21 单，贡献度约 2.18%。Top 5 合计贡献约 9.45%，集中度较低。这说明：

- 购买增长并非由某一个类目爆发带动，而是**多类目普涨**。
- 类目 965809、1464116、4918438、1575622、2297500 均有正向增量，但单个类目的解释力有限。
- 由于缺乏类目 DAU/流量数据，无法判断是“流量灌入多类目”还是“某类目活动外溢”。**建议后续补充类目级流量与转化数据。**

### 3. 时段：晚间 16—21 点是增量主战场

12月2日相对12月1日的时段购买增量 Top 5 全部集中在 16—21 点：

| 时段 | 购买增量 | 贡献度 |
|---|---:|---:|
| 21点 | +127 | 13.19% |
| 17点 | +123 | 12.77% |
| 16点 | +105 | 10.90% |
| 19点 | +97 | 10.07% |
| 20点 | +74 | 7.68% |

Top 5 合计贡献约 54.6%，说明**超过一半的购买增量来自傍晚至晚间 5 个小时**。这与周末用户晚间活跃习惯一致，也可能与平台晚间活动/投放节奏有关。建议重点复盘 16—21 点的运营动作（如 push、直播、限时折扣），确认增量来源是否可复制。

### 4. 用户类型：DAU 增量几乎全部来自“仅 12月2日活跃”的用户

DAU 净增量拆解显示：

- 两天均活跃用户：14,258 人，delta_contribution = 0；
- 仅 12月2日活跃（gained_1202_only）：4,860 人，delta_contribution = +4,860；
- 仅 12月1日活跃、12月2日流失（lost_1201_only）：265 人，delta_contribution = -265。

**净增量 = 4,860 - 265 = 4,595 人**，与 DAU 从 14,523 增至 19,118 的增量一致。

这说明：

- 12月2日 DAU 增长**几乎完全由新增活跃用户驱动**，而非原有用户活跃度提升。
- 流失用户仅 265 人，留存基本盘稳定。
- 但新增活跃用户的购买转化尚未完全体现：buy_per_dau 下降，说明这批新增用户更多处于浏览/加购阶段，或为低意图流量。
- **注意：** 这里不能写成“新用户贡献了 DAU 增量”，因为 gained_1202_only 仅表示“12月1日不活跃、12月2日活跃”，其中可能包含回流用户，不一定是严格意义上的新注册用户。当前数据无法区分“纯新用户”与“回流用户”，这是本报告的一个局限。

## 三、可执行业务建议

### 建议 1：复盘 16—21 点晚间运营动作，沉淀可复制的增量打法

12月2日超过一半的购买增量集中在 16—21 点，且 21 点贡献最高（13.19%）。建议：

- 拉取 16—21 点的 push、直播、限时活动、投放计划，确认哪些动作与购买增量时间吻合；
- 对 21 点增量最高的时段，检查是否有特定品类/单品活动，评估是否可在下一个周末复用；
- 若增量主要来自付费投放，需进一步核算 ROI，避免“增量不增利”。

### 建议 2：针对“仅当日活跃”的 4,860 用户做二次触达，提升转化

12月2日新增活跃用户 4,860 人，但 buy_per_dau 下降，说明这批用户购买转化不足。建议：

- 对 12月2日活跃但未购买的用户，在 12月3日或下一个活跃日进行定向触达（如优惠券、加购提醒、个性化推荐）；
- 重点覆盖 16—21 点活跃时段，与增量高峰对齐；
- 监测这批用户的次日/7日转化率，评估触达效果。

### 建议 3：补充类目与流量来源数据，定位增量根因

当前类目增量分散，Top 5 合计贡献不足 10%，无法判断增长是“多类目自然普涨”还是“特定活动外溢”。建议：

- 补充类目级 DAU、PV、加购数据，计算各类目的流量-转化漏斗；
- 补充流量来源（自然/付费/站内/站外）维度，判断 DAU 增量来源；
- 若发现某类目或某渠道贡献显著，可在下一个周末加大投入；若为普涨，则需评估是否为大促预热等外部因素。

**局限说明：**

- 本报告基于用户级抽样 19,476 个用户 / 196.7 万行行为记录，指标为抽样口径，绝对值可能与全量存在偏差，但趋势判断可用。
- 用户归因中“gained_1202_only”仅表示 12月1日不活跃、12月2日活跃，无法区分纯新用户与回流用户。
- 类目与时段归因仅基于购买增量，缺乏流量与转化率数据，无法判断增量是流量驱动还是转化驱动。
- 异常检测的 z-score 基于移动均值，未考虑大促、节假日等外部因素，需结合运营排期综合判断。
