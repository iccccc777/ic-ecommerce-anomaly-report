# AI 日报

## 运行方式

先运行本地模板：

```powershell
cd C:\Users\ASUS\Desktop\project_a
python python\07_ai_daily_report.py
```

这会在没有 API Key 时生成一份可读的日报初稿模板。

## 接入 DeepSeek

1. 到 DeepSeek 开放平台注册并创建 API Key。
2. 在项目根目录创建 `.env` 文件（可参考 `.env.example`）：

```text
DEEPSEEK_API_KEY=sk-你的Key
```

3. 重新运行：

```powershell
python python\07_ai_daily_report.py
```

## 接入通义千问

1. 到阿里云百炼创建 API Key。
2. 在 `.env` 文件中设置：

```text
DASHSCOPE_API_KEY=sk-你的Key
```

3. 重新运行脚本，脚本会自动使用 `qwen-plus`。

## 重要提醒

AI 日报只是初稿。最终报告必须人工校准，保留可复现的数据口径和结论。
`07_ai_daily_report.py` 会把模型、提示词、返回内容和时间写入 `outputs/ai_call_log.json`，方便保留人工校准痕迹。
人工校准后的最终版本放在 `outputs/daily_report_calibrated.md`。
