# Streamlit 看板

启动命令：

```powershell
cd C:\Users\ASUS\Desktop\project_a
streamlit run python\08_streamlit_dashboard.py
```

如果提示没有 `streamlit`，使用 Anaconda 环境：

```powershell
D:\Anaconda\python.exe -m streamlit run python\08_streamlit_dashboard.py
```

浏览器默认打开：

```text
http://localhost:8501
```

看板包含：

- DAU、PV、购买、转化率指标卡
- 核心指标趋势
- 购买漏斗
- 留存率表
- 异常检测表
- 类目、时段、用户归因
- AI 日报初稿
