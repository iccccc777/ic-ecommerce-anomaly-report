# 漏斗与留存

## 漏斗

本数据集按行为事件记录，漏斗顺序为：

```text
浏览 pv -> 收藏 fav / 加购 cart -> 购买 buy
```

当前 `funnel.csv` 输出的是窗口期内用户重叠率：浏览、收藏、加购、购买分别有多少用户，以及各行为用户占浏览用户的比例。它不是严格的行为顺序漏斗，因为同一个用户可能在窗口内多次完成不同行为，顺序并不固定。

如果要在面试中展示严格漏斗，需要按用户行为时间序列计算“首次浏览 -> 首次加购/收藏 -> 首次购买”的路径。

## 留存

留存定义：

- 用户首日：该用户在 `behavior_clean` 中第一次出现的行为日期
- Day 0：首日当天
- Day N：首日后第 N 天仍有任意行为的用户比例

留存公式：

```text
Day N 留存率 = 首日后第 N 天仍有行为的用户数 / 首日用户数
```

## 注意

留存分析只使用 `behavior_clean` 视图，避免脏时间戳影响分组。
当前数据集只有 9 天，`first_day` 是用户在该窗口内首次出现日，不是真实注册日；Day 1 留存偏高可能来自窗口左截断，不能当作真实获客留存解读。
