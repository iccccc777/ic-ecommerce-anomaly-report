# 数据说明：淘宝用户行为数据集

## 数据来源

- 阿里云天池：淘宝用户行为数据集
- 页面：https://tianchi.aliyun.com/dataset/649
- 时间范围：2017 年 11 月 25 日到 2017 年 12 月 3 日
- 规模：100 万随机用户，约 1 亿条行为记录
- 原始文件常见文件名：`UserBehavior.csv`
- 本地文件：`data/UserBehavior_raw.csv`，100,150,807 行，3,672,347,465 字节
- 本地文件 SHA256：`46FDD7D389C1DDC7922EB7D9014AF5573A4A3045DA28C6C46197636873D8F1A9`

如果天池需要登录或下载不顺利，也可以搜索“淘宝用户行为数据集 UserBehavior.csv”找公开镜像，但要记录你实际使用的下载地址，避免报告里无法说明数据来源。

## 字段含义

| 字段 | 含义 | 示例 |
|---|---|---|
| user_id | 用户 ID | 10001082 |
| item_id | 商品 ID | 285259775 |
| category_id | 类目 ID | 4756105 |
| behavior_type | 行为类型 | pv / cart / fav / buy |
| timestamps | 行为时间戳 | 1511544070 |

行为类型说明：

- `pv`：浏览
- `cart`：加入购物车
- `fav`：收藏
- `buy`：购买

注意：原始数据没有表头。不同渠道下载的版本分隔符可能不同，你当前这份文件是逗号 `,` 分隔；如果以后换成其他版本，先打开前几行确认分隔符。

## 建议的数据处理策略

1. 先不要直接分析全部 1 亿行，采用用户级随机抽样：按 `user_id` 的稳定哈希保留约 2% 用户，再保留这些用户的全部行为记录。
2. 本次抽样得到 19,476 个用户、1,966,733 条行为记录；清洗后为 1,965,596 条。
3. 报告中明确写“用户级抽样 + 抽样用户数 + 抽样行数”，这是数据管理能力的一部分。
4. 用户级抽样比行级抽样更能保留用户行为连续性，避免 DAU、留存、新老用户口径被行级抽样破坏。
5. 如果想挑战更大规模，可以调高抽样比例后重跑 `python/02_build_sqlite.py`。
