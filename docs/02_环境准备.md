# 环境准备

## 1. 安装 Python

如果电脑已经装了 Anaconda，就使用 Anaconda Prompt。如果没有，可以安装 Anaconda 或 Python 3.10+。

打开命令行，确认 Python 可用：

```powershell
python --version
```

正常情况下会显示类似 `Python 3.10.x` 或更高的版本。

## 2. 安装 VS Code

如果已经装了 VS Code，安装下面两个扩展：

- Python
- Jupyter

## 3. 创建项目环境

在命令行进入项目目录：

```powershell
cd C:\Users\ASUS\Desktop\project_a
```

创建虚拟环境：

```powershell
python -m venv .venv
```

激活环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

如果 PowerShell 提示无法加载脚本，用这个命令临时放行当前终端：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## 4. 安装依赖

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

如果网络慢，可以换成清华镜像：

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 5. 确认环境完成

运行：

```powershell
python -c "import pandas, numpy, sqlite3, matplotlib; print('ok')"
```

输出 `ok` 就说明基础环境已经准备好了。

## 6. SQL 工具选择

本地练习建议先用 SQLite：

- 优点：不需要安装数据库服务，Python 自带 `sqlite3`
- 简历上照样可以说“用 SQL 建立数仓表结构”

等流程跑通后，如果想更贴近岗位要求，再装 MySQL 或 PostgreSQL，把 SQL 原样迁移过去。
