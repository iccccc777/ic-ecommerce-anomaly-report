# 电商业务经营日报（人工校准版）

## 一、核心指标概览

12月2日（周六）与12月3日（周日）连续两天DAU均突破1.9万。相对不含当天的前3日移动平均，12月2日高出32.96%，12月3日高出18.97%；较上周同期（11月25日/26日）分别增长38.5%和35.0%。

购买转化方面，12月2日buy事件数5080次，较上周同期增长31.2%；12月3日buy事件数5258次，较上周同期增长29.1%。整体购买转化率（buy_to_pv）维持在2.10%到2.17%之间，与12月1日的2.15%接近，说明流量增长没有明显稀释整体购买/浏览效率。不过，人均购买次数从12月1日的0.283降至12月2日的0.266、12月3日的0.276，说明新增活跃用户的人均购买贡献仍低于原有活跃盘。

**核心结论**：本周末DAU和购买量均出现强异动（最大绝对z-score>2），购买增长与流量增长同步；整体buy_to_pv保持稳定，但人均购买次数下降，增量用户尚未完全转化为购买。

## 二、异动定位

### 1. 同星期基线对比

- **12月2日（周六）**：DAU较11月25日（周六）增长38.5%，buy增长31.2%，DAU z-score达2.49（strong）。
- **12月3日（周日）**：DAU较11月26日（周日）增长35.0%，buy增长29.1%，buy z-score达2.53（strong）。
- **说明**：排除星期效应后，本周末用户活跃度和购买行为均出现实质性增长，并非周期性波动。

### 2. 类目维度

购买增量Top 5类目贡献度合计约9.4%，单个类目贡献度最高仅2.18%（类目965809和1464116），增量分散在多个类目，未出现单一爆款类目主导的情况。这说明增长是广谱性的，可能源于平台整体流量或促销活动覆盖多品类；由于单类目购买增量只有21次，此结论需要结合PV、加购、收藏进一步验证。

### 3. 时段维度

购买增量高度集中在晚间时段：

- **21点**增量最大（+127，贡献13.19%）
- **17点**（+123，贡献12.77%）、**16点**（+105，贡献10.90%）、**19点**（+97，贡献10.07%）、**20点**（+74，贡献7.68%）
- **说明**：16-21点合计贡献超过54%的购买增量，晚间时段是本次异动的主要驱动窗口，可能与周末晚间用户集中购物、促销活动或内容推送有关。

### 4. 用户类型维度

DAU净增量拆解显示：

- **新增活跃用户**（gained_1202_only）：4860人，贡献净增量4860，占12月2日DAU的25.4%。
- **流失活跃用户**（lost_1201_only）：265人，对净增量为负向影响。
- **既有活跃用户**（both_days）：14258人，占12月2日DAU的74.6%，保持稳定。
- **说明**：DAU增长主要由新增活跃用户驱动（净增4860人），而非存量用户活跃度提升。当前只能确认这些用户12月1日未活跃，不能确认他们是新注册用户；外部渠道拉新只是待验证的假设。

## 三、业务建议

1. **强化晚间时段运营**：16-21点是购买增量核心时段，建议在该时段增加push推送、首页banner资源位，并针对Top增量类目（如965809、1464116等）设置限时优惠或组合购，进一步放大转化效率。
2. **追踪新增活跃用户留存与二次转化**：周末新增活跃用户4860人，但需关注其后续留存。建议对该人群打标，在接下来7天内做定向触达（如优惠券、个性化推荐），避免一次性流量；同时分析其行为路径和来源，评估触达ROI。
3. **验证增长归因，防止误判**：当前数据为抽样用户级数据，且未包含活动信息、渠道来源等外部变量。建议与运营团队核对本周末是否有大型促销、广告投放或内容热点；若无明确活动，则需进一步排查数据口径（如爬虫、刷量）或外部事件（如竞品停服）影响，避免将偶发因素视为可持续增长。

## 四、局限

本报告基于用户级抽样数据（19,476用户/196.7万行），非全量数据；DAU净增量拆解为净变化值，未区分新增活跃用户的质量与来源；类目和时段分析仅覆盖购买增量Top 5，未包含全部类目；未获取活动、渠道等外部数据，归因结论需结合业务侧信息进一步验证。
